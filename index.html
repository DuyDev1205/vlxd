              Kết nối Google Drive

              App cần một OAuth Client của Google (làm 1 lần, miễn phí):

              1. Vào Google Cloud Console, tạo project và bật Google Drive API.
              2. OAuth consent screen: chọn External, thêm email của bạn vào Test users.
              3. Credentials → Create OAuth client ID → loại Web application, thêm Authorized redirect URI:
              4. Chép Client ID và Client secret vào file .env (xem .env.example), rồi khởi động lại app.
